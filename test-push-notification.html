📖 使用說明

  1. 點擊「請求通知權限」按鈕允許瀏覽器通知
  2. 點擊「訂閱推播」按鈕取得 FCM Token
  3. 點擊「測試本地通知」查看通知效果
  4. 複製 Token 用於後端發送推播測試

📡 後端發送測試

使用 Firebase Admin SDK 或 REST API 發送推播:

POST https://fcm.googleapis.com/v1/projects/yoni-a0268/messages:send
Authorization: Bearer [YOUR_ACCESS_TOKEN]

{
  "message": {
    "token": "[FCM_TOKEN]",
    "notification": {
      "title": "YONI 測試通知",
      "body": "這是一則測試推播消息"
    },
    "webpush": {
      "fcm_options": {
        "link": "https://jeffrey0117.github.io/yoni/"
      }
    }
  }
}
